## Descripción del proyecto

Aplicación móvil desarrollada con React Native y Expo que permite a un usuario registrarse, iniciar sesión y ver su perfil, usando Firebase como backend (autenticación y base de datos).

## Dependencias utilizadas

- expo
- react
- react-native
- firebase
- @react-navigation/native
- @react-navigation/native-stack
- react-native-screens
- react-native-safe-area-context
- react-native-gesture-handler
- react-native-dotenv
- @react-native-async-storage/async-storage
